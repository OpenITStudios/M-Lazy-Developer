# Known Limits

This file records **current capability limits** relevant to Map Bug Audit.

A limit is not a bug and is not automatically a Detection Development task.

## Rules

- State the exact unsupported proof/semantic.
- Distinguish platform limit from M-Bedrock-Dev implementation limit.
- Include the strongest proof currently available.
- Prefer version-scoped statements.
- Remove or revise limits when Detection Benchmark proves capability changed.
- Never copy undocumented numeric Minecraft limits into permanent truth without evidence.

## Examples of limit shape

```text
Limit
Scope/version
Current capability
Unsupported claim
Fallback/manual check
Detection Development owner
Last evidence
```

Map-specific values do not belong here.
