# Reliability Corpus

Calibration cases from past real-map inspections were cleared at the user's request. The current `calibration.json` contains no map cases. The current `regressions.json` retains only standalone synthetic fixture cases; `acceptance.json` retains synthetic blind test cases. The former real-map detection case registry is empty.

Any future real-map scoring requires a newly supplied immutable map, fresh evidence, independently frozen expectations and a matching engine execution receipt. A previous map name, issue, fingerprint or Git history record cannot prove behavior in a newly selected map.

Synthetic fixtures test generic analyzer logic. They are not prior gameplay facts and do not establish whole-map bug recall.
